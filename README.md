# portfolio-personal
Portfolio web personal desarrollado con HTML y CSS puro, sin frameworks ni librerías externas.

Descripción

Sitio de una sola página que presenta información personal/profesional y una galería de proyectos. Incluye secciones de inicio (hero), sobre mí, portafolio y contacto, con un diseño responsive adaptado a móvil, tablet y escritorio.

Tecnologías
HTML5 semántico
CSS3 (variables, Flexbox, Grid, media queries)
Estructura del proyecto
portfolio-personal/
├── index.html
├── styles.css
├── img/
└── README.md
Características
Maquetado semántico (header, nav, main, section, article, footer)
Menú de navegación con Flexbox
Galería de proyectos con CSS Grid
Formulario de contacto (nombre, email, mensaje)
Diseño responsive mediante media queries
Variables CSS centralizadas en :root
Cómo verlo

Abre index.html en el navegador, o usa la extensión "Live Server" en VS Code para previsualizarlo con recarga automática.
